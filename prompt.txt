### **Steps to Implement**:

2. **Create Blockonomics Service**:

**Path**: `app/Services/BlockonomicsService.php`

```php
<?php

namespace App\Services;

use GuzzleHttp\Client;

class BlockonomicsService
{
    protected $client;
    protected $apiKey;

    public function __construct()
    {
        $this->client = new Client();
        $this->apiKey = env('BLOCKONOMICS_API_KEY'); // Ensure the API key is in .env
    }

    // Method to generate a new Bitcoin address
    public function createAddress()
    {
        $response = $this->client->post('https://www.blockonomics.co/api/new_address', [
            'form_params' => [
                'api_key' => $this->apiKey,
            ]
        ]);

        $data = json_decode($response->getBody()->getContents(), true);
        return $data['address']; // Return the generated Bitcoin address
    }

    // Method to generate the QR code for the Bitcoin address
    public function getQRCode($address)
    {
        return 'https://chart.googleapis.com/chart?chs=300x300&cht=qr&chl=bitcoin:' . $address; // Returns QR code URL
    }
}
```

---

3. **Create Payment Controller**:

**Path**: `app/Http/Controllers/PaymentController.php`

```php
<?php

namespace App\Http\Controllers;

use App\Services\BlockonomicsService;
use Illuminate\Http\Request;

class PaymentController extends Controller
{
    protected $blockonomicsService;

    public function __construct(BlockonomicsService $blockonomicsService)
    {
        $this->blockonomicsService = $blockonomicsService;
    }

    // Generate Bitcoin payment address and QR code
    public function createPayment(Request $request)
    {
        // Generate new address
        $address = $this->blockonomicsService->createAddress();

        // Generate QR code for the address
        $qrCodeUrl = $this->blockonomicsService->getQRCode($address);

        // Return the payment page with Bitcoin address and QR code
        return view('payment', compact('address', 'qrCodeUrl'));
    }
}
```

---

4. **Create Routes**:

**Path**: `routes/web.php`

```php
use App\Http\Controllers\PaymentController;

// Route to display the payment page
Route::get('create-payment', [PaymentController::class, 'createPayment']);
```
